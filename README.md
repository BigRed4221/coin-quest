## 🎮 What's Coin Quest?

Coin Quest is a fun, action-packed **2D platformer game** where you help Carl Quest (a guy in his 30s) reclaim his house after an embarrassing eviction. His crime? A massively overdue library book fine!

Jump over obstacles, punch enemies, collect coins, and defeat quirky foes like:
- 🐦 Angry pigeons that dive-bomb from above
- 🐕 Stray dogs blocking your path  
- 🚜 Runaway lawnmowers
- 👮 Officer Bob on his ridiculous Segway (the boss!)

It's retro, it's funny, and you'll need quick reflexes and good timing to win!

## 🚀 Getting Started

### What You Need
- A **modern web browser** (Chrome, Firefox, Safari, Edge—any recent one will do!)
- **Node.js** installed on your computer ([download here](https://nodejs.org/) if you don't have it)
- That's it! No special gaming hardware needed.

### Installation & Running

1. **Open a terminal/command prompt** and navigate to the Coin Quest folder:
   ```bash
   cd path/to/coin-quest
   ```

2. **Install dependencies** (one-time setup):
   ```bash
   npm install
   ```

3. **Start the game**:
   ```bash
   npm run dev
   ```

4. **Open your browser** and go to the URL shown in your terminal (usually `http://localhost:5173`)

5. **Play!** 🎮

### Stopping the Game
Press `Ctrl+C` in your terminal window.

## 🎮 How to Play

### Controls
- **Move Left/Right**: Press `A` or `D`
- **Jump**: Press `W`
- **Crouch/Duck**: Press `S` (dodge those dive-bombing pigeons!)
- **Attack**: Click the mouse or press `J` (hit multiple times for a combo!)
- **Special Skills**: Press `E` or `F` (unlock as you play)
- **Rest at Campfire**: Press `R` (to heal and manage your abilities)

### The Story
Start on Grandma's porch with an eviction notice. Fight your way through the suburbs:
- Avoid obstacles (trash cans, fences, cardboard boxes)
- Defeat enemies and collect coins
- Find the campfire checkpoint to heal up
- Face off against Officer Bob to escape and unlock new adventures!

## 🛠️ Building from Source (For Developers)

To build the game for distribution:
```bash
npm run build
```

The optimized game will be in the `dist/` folder.

## 💡 Tips & Tricks

- **Enemies have patterns** — watch how they move before attacking
- **Campfires heal you** — use them to recharge when things get tough
- **Combo attacks are powerful** — hold `J` or click rapidly for bigger damage
- **Crouch saves you** — many attacks can be dodged by crouching
